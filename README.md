# ♟️ Flutter Chess App

A simple yet complete **two-player chess game** built with **Flutter**, playable on a **single device**.  
The app features full chess rules, smooth piece interactions, move highlights, and endgame detection — all wrapped in a clean, intuitive interface.

## 🚀 Features

- **Full Chess Rules** — includes castling, en passant, pawn promotion, and check/checkmate detection  
- **Move Validation** — ensures only legal moves can be made  
- **Local Multiplayer** — two players can play on a single device, taking turns  
- **Move Highlights** — visually shows available moves and the last move made  
- **Game State Management** — handles turns, board updates, and resets cleanly  

---

## 🛠️ Tech Stack

- **Framework:** Flutter (Dart)  
- **State Management:** setState

## 📦 Getting Started


### 2️⃣ Install Dependencies
